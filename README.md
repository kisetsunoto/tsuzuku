# つづく

休んでも途切れない習慣トラッカー。

everyday のボードUIを下敷きに、**「N日に1回」のペース設定**と**延命**を足したもの。
毎日やることを前提にせず、決めたペースを守れていれば連鎖は続く。

## 記録の4状態

セルをタップするたびに切り替わる。

| 表示 | 意味 |
|---|---|
| 太いリボン | 実施した日 |
| やや細い | お休み（ペース上、やらなくてよい日） |
| いちばん細い | 延命（半分だけ／やむを得ない事情）。その日は連鎖の日数計算から差し引かれ、回数にも数えない |
| 空白 | 未実施 |

リボンは連鎖ごとに一本の図形として描かれ、太さと色がなだらかに変化する。
濃さは1実施ごとに一段濃くなり10実施で最濃。10を超えた連鎖は、初日が最薄・最終日が最濃になるよう全体を割り直す。

長押しでその日のメモ。ボード上には先頭3文字が出る。

## 使い方

- 左上「⋯」… 休止中の習慣の管理、JSONの書き出し・読み込み
- 「HABITS ⇅」… 並び替え
- 右上「＋」… 習慣を追加
- ボードを右へスワイプ … 現在の連続回数・最高連続回数・合計回数
- 習慣名をタップ … 統計、メモ一覧、編集、休止、削除

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
npm run preview  # ビルド結果を確認
```

## デプロイ

`main` に push すると GitHub Actions が自動で GitHub Pages に公開する。
初回だけリポジトリの **Settings → Pages → Build and deployment → Source** を
**GitHub Actions** に変更しておくこと。

`vite.config.js` の `base` は `"./"` にしてあるので、リポジトリ名を変えても設定は触らなくてよい。

## データ

記録は端末の localStorage に `streaks:habits` というキーで入る。
サーバーには何も送らない。そのため**ブラウザのデータを消すと記録も消える**。
機種変更やバックアップは「⋯ → 書き出し」でJSONを保存し、新しい端末で「読み込み」する。

## ホーム画面に追加

- iOS … Safari で開き、共有 → ホーム画面に追加
- Android … Chrome のメニュー → アプリをインストール
